# MediScribe interface direction

- Make every interface feel deliberately authored for a clinical workflow. Avoid generic “AI SaaS” compositions, filler copy, glow effects, glassmorphism, and ornamental dashboard clutter.
- Do not introduce random SVG illustrations or decorative icon sets. Icons must be functional, necessary, and part of an established system; prefer typography and layout when an icon adds no meaning.
- Avoid cylindrical controls, pill buttons, and excessive rounded cards. Default to square geometry or a restrained 0–4px radius; use larger radii only when the content model genuinely calls for it.
- Do not default to blue, purple, neon, or blue–purple gradients as an “AI” palette. The staff-access system uses warm paper, charcoal ink, muted oxide, and restrained neutral lines.
- Use hierarchy, spacing, rules, and strong editorial typography before adding containers. A section should not become a card merely to separate it.
- Keep motion brief and functional. Respect `prefers-reduced-motion` and never use ambient floating or pulsing decoration.
- Preserve keyboard focus, labels, contrast, responsive behavior, and reduced-motion support in all visual changes.
